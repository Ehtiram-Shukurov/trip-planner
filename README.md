# Trip Planner

A travel planning web app built with a team of five for CSCI 5117 at the University of Minnesota. Plan trips, build day-by-day itineraries, get location suggestions powered by Google Maps, and document memories with photos and journal entries.

**Live demo:** https://big-chungus-project2.web.app/

---

## What it does

Start by searching for a destination and picking your travel dates. From there you build out each day with activities, locations, and notes. The app suggests nearby places using Google Places API so you're not starting from scratch. Once the trip happens, you can come back and add photos and journal entries for each day.

Works on mobile with direct camera access, or on desktop with file upload.

## Stack

React, Firebase (Hosting + Firestore), Google Maps/Places API
